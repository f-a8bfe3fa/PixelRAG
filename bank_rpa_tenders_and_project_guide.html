本文档按你要求，把 2024–2026 年银行 RPA / 机器人流程自动化 / 数字员工相关公开招标、中标及供应商征集公告做了系统整理，并据此提炼出可直接练手的“仿真实战项目”方案，方便你补项目经验、准备面试。

一、为什么要先看招标文件？

银行招标文件直接暴露了甲方真正关心的东西：

  • 业务场景：对账、票据、税务、监管报送、反洗钱、信贷审批等；
  • 技术要求：RPA 控制台/设计器/机器人许可、信创适配、MySQL/Redis、Python/.NET/Java、7×24 稳定性、审计日志；
  • 交付要求：项目经理/业务分析师/开发工程师角色、PMP/RPA 认证、CMMI/ISO 资质、POC 测试、培训与文档。

看懂这些后，你就能反向设计一个“看起来像银行项目”的个人作品，而不是只会拖拽几个模块。

四、招标文件里透出的技术要求

综合华夏银行、兴业银行、民生银行等公告，银行对 RPA 供应商/工程师的核心要求如下：

  • 平台组件：机器人控制台（Console）、机器人设计器（Studio）、机器人执行器（Robot/Runner）、无人值守/有人值守许可。
  • 信创适配：支持统信、麒麟、红旗等国产操作系统，支持鲲鹏、飞腾、海光、龙芯等国产 CPU，支持腾讯/阿里/华为云服务器。
  • 开发语言：C# / .NET（WPF/WWF/Winform）、Java、Python 至少精通一种；前端需 Vue/React/Angular 之一。
  • 数据库/中间件：MySQL、Redis、Elastic Search、MQ；Spring Boot / Spring Cloud。
  • 通信协议：HTTP(S)、WebSocket、GRPC、Named Pipe。
  • 智能化：OCR、NLP、大模型生成 RPA 代码、智能代码助手。
  • 稳定性：7×24 小时稳定运行、异常自动重试、人工介入机制、完整审计日志。
  • 安全合规：通过第三方安全测试、等保、密码测评、ISO27001、CMMI3/5、TMMI5 等。
  • 项目管理：PMP、RPA 厂商认证、需求分析、流程挖掘、POC 测试、培训与文档。

这些信息直接决定了你练手项目应该覆盖哪些技术点，也决定你在面试时该强调什么。

五、可写进简历的“仿真实战项目”方案

下面给出 3 个贴近真实招标需求、技术栈与岗位要求匹配的项目方案。建议先挑项目一或项目二完整做完，能跑通、能演示、能讲清楚，比做十个半成品更有用。

项目一：业务处理监督中心 RPA 机器人（基于北京农商银行公告复现）

项目背景：参考北京农商银行“业务处理监督中心 RPA 机器人流程自动化项目”[5]，模拟银行运营后台每日重复性操作。

核心功能：

  • 自动登录“人行 ACS 系统”模拟页面，下载对账文件，与行内 Excel 账务进行核对，输出差异报告；
  • 自动登录“同城票据交换信息管理平台”下载提入明细，完成“票据集中提回系统”签到与数据导入；
  • 自动抓取票据系统数据，按模板生成会计简报，并定时发送邮件给指定人员；
  • 异常处理：页面加载失败、数据缺失、对账不平自动重试并记录日志。

技术栈：UiPath / 影刀 RPA / 来也 UiBot（三选一）+ Python 辅助处理 Excel + MySQL 记录运行日志 + SMTP 邮件。

输出物：需求说明书、流程设计文档、RPA 流程源码、测试用例、运行日志样例、操作手册。

简历写法：“基于北京农商银行公开招标文件，独立复现‘业务处理监督中心 RPA 机器人’POC，覆盖 ACS 对账、票据导入、简报生成 4 个场景，设计异常重试与日志审计机制，输出完整需求/设计/测试文档。”

项目二：财务税务申报 RPA 流程机器人（基于宁波银行公告复现）

项目背景：参考宁波银行“财务税务申报 RPA 流程建设项目”[3]，聚焦税务合规与财务运营效率。

核心功能：

  • 从财务系统/Excel 中采集个税、印花税、财务报表、重点税源报表等数据；
  • 进行表内/跨表逻辑校验，自动识别异常值并提示人工介入；
  • 模拟登录电子税务局，自动填报并提交申报表（可用沙箱或 Mock 页面替代）；
  • 自动读取、下载、拆分报表，按总行/分行/支行维度分发，并调整尾差。

技术栈：Python + Selenium/Playwright + pandas + openpyxl + OCR（Tesseract/EasyOCR）+ MySQL + APScheduler 定时调度。

输出物：税务申报流程设计图、校验规则表、Python 脚本、MySQL 数据库脚本、运行报告。

简历写法：“参考宁波银行税务 RPA 招标文件，使用 Python+Selenium 实现多税种申报数据采集、校验、填报与分发，建立异常重试与尾差调整机制，覆盖个税、印花税、财务报表等核心税种。”

项目三：监管报送数据补录机器人（基于农信/农商行场景复现）

项目背景：参考安徽农信“机器人流程自动化平台 + 9 种场景”[43]、淮安农商银行“统计分析平台 RPA 自动补录”[47]。

核心功能：

  • 从多个 Excel/CSV/数据库表抽取监管报送所需字段；
  • 按 1104 报表模板进行字段映射、数据清洗、缺失值补录；
  • 生成校验报告：空值率、同比异常、跨表勾稽关系检查；
  • 将结果写入 MySQL，并邮件通知业务人员复核。

技术栈：Python + pandas + SQLAlchemy + MySQL + openpyxl + logging。

输出物：数据映射文档、Python ETL 脚本、MySQL 表结构、校验规则说明、运行日志。

简历写法：“基于农信机构公开招标文件，设计监管报送数据补录机器人，完成多源数据抽取、模板映射、缺失补录与异常校验，提升报送数据质量。”

六、简历 / 面试表达建议

  • 不要伪造工作经历。可以写“个人 RPA 仿真实战项目（基于华夏银行/北京农商行/宁波银行公开招标文件）”。
  • 突出项目管理思维：需求调研 → 流程设计 → 开发配置 → 单元测试 → 集成测试 → 上线运维 → 培训交付，完整走一遍。
  • 用数字说话：“覆盖 X 个场景”“异常重试 Y 次”“生成 Z 张报表”“节省约 N 工时/月”。
  • 强调岗位匹配点：Python、MySQL、UiPath/UiBot/影刀、业务调研、POC 测试、技术文档、培训。
  • 准备演示：面试时带一个 3–5 分钟的录屏或现场演示，比口头描述更有说服力。

七、推荐学习路径与资源

  • RPA 工具：UiPath Community Edition（免费）、影刀 RPA（社区版免费）、来也 UiBot 社区版。
  • 官方认证：UiPath RPA Associate、影刀 RPA 开发者认证、来也 UiBot 认证。
  • Python 自动化：Selenium/Playwright 网页自动化、openpyxl/pandas Excel 处理、APScheduler 定时任务。
  • 练手网站：RPA Challenge（网页录入练习）、模拟电子税务局/ACS 页面（可用本地 HTML 或公开测试环境）。
  • 面试准备：把本报告中“高频场景”和“技术要求”变成你能讲清楚的案例，尤其是异常处理和日志审计。
